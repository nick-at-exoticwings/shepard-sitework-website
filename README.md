# Shepard Sitework & Clearing LLC — Website

Pure HTML, CSS and JS. No libraries, no build step. Open `index.html` in a browser.

- `css/styles.css` — all styles; sizes in rem/em, mobile-first.
- `js/main.js` — small vanilla JS (mobile nav, footer year).
- `images/` — stock photos go here (sized per the image size requests).
